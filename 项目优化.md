#### 任务 1.1：地图坐标系对齐（OSM路网 → 百度BD09）

| 项目       | 内容                                                                                                                                                                                                                                                                                                   |
| :------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **负责人**  | 前端开发                                                                                                                                                                                                                                                                                                 |
| **问题描述** | OSM路网数据为WGS84坐标系，百度地图底图为BD09坐标系，存在10-30米偏移，导致路网线条悬浮、错位。                                                                                                                                                                                                                                              |
| **执行步骤** | 1. 在前端项目中引入 `gcoord` 坐标转换库。2. 封装函数 `convertGeoJSONToBD09(geojson)`，遍历 `features`，对每个坐标点调用 `gcoord.transform(lng, lat, gcoord.WGS84, gcoord.BD09)`。3. 找到加载OSM路网GeoJSON并渲染的代码位置，将数据先传入转换函数再渲染。4. 对建筑物、POI等所有基于WGS84的GIS数据，执行相同转换流程。5. **删除**前端代码中初始化OSM底图瓦片图层的部分，确保只使用百度地图作为底图。6. 清理UI中任何切换底图的下拉菜单或按钮。 |
| **验收标准** | - 路网线条与百度地图底图道路完全重合，无明显偏移。- 建筑物点位正确落在底图对应建筑轮廓内。- 截图中无法找到OSM底图控件。                                                                                                                                                                                                                                     |
